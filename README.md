## Android Local Manifests for Crave.io Builds
### Usage

```Lunaris-Aosp
crave run --no-patch -- "curl https://raw.githubusercontent.com/andrey167/crave_build/refs/heads/Platina/LunarisAOSP.sh | bash"
```
```Derpfest=Aosp
crave run --no-patch -- "curl https://raw.githubusercontent.com/andrey167/crave_build/refs/heads/Platina/DerpfestAosp.sh | bash"
```
